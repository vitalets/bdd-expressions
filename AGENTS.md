# Contributor instructions

Read `docs/specification.md` before changing syntax, matching, or public APIs.
Consult `docs/implementation-plan.md` for progress and remaining work.
Update the specification and tests when behavior changes, and record significant
decisions in `docs/decisions.md`. Run `npm run check` before submitting changes.

Update `CHANGELOG.md` under Unreleased for meaningful user-facing changes.
Use `npm run fmt:write` for formatting and `npm run lint` for linting.
